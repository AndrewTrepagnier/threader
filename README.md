# Threader

This is a development repo for a larger project that intends to be an archiving tool for GitHub/Zulip PRs and conversations.
The project's final objective is still unclear and may very well morph into something different over its development. However, the premise is for it to be a stand-alone tool for skimming published Pull Requests and flattening the markdown into text files for archival. This tool will typically be used for large, highly technical, “report-style” PRs that I enjoy and want to read more closely.

At the moment, the scripts are manual API calls; however, this may turn into a CLI agent in the future.
